Our Free Model 2.5.4 · Windows 桌面客户端（含出口代理）
=======================================================

安装
----
双击「Our Free Model Setup 2.5.4.exe」，按向导完成安装
（默认装到当前用户目录，可在向导里改路径）。

安装后桌面与开始菜单会有「Our Free Model」快捷方式，双击即可启动。


使用
----
启动后先显示启动动画，随后自动打开应用内窗口（就是原版桌面端那个界面）。
首次使用：

  1. 窗口打开后即是管理页面，无需密码（启动时已带一次性登录令牌）。
  2. 左侧「服务设置」→「出口代理」卡片：
       - 打开「启用出口」
       - 订阅模式：粘贴 Clash/V2Ray 订阅链接，「mihomo 路径」留空自动查找
         本机 mihomo（Clash Verge 会附带 verge-mihomo.exe）
       - 单代理模式：直接填 socks5://127.0.0.1:10808 等地址
       - 点「保存设置」
  3. 卡片会显示当前出口、当前最佳节点（含延迟）、opencode 往返耗时。
  4. 关闭窗口不会退出程序，而是隐藏到托盘；右键托盘图标 →
     「打开面板」重新显示，「退出」才真正关闭并释放数据锁。

API Key 与设置保存在用户目录 ~/.our-free-model/settings.json。

端口默认 18900，被占用时自动顺延（控制台会打印实际端口）。
可用环境变量 OFM_HOME 指定其他数据目录。


与绿色版的区别
--------------
- 这是应用级客户端：有窗口、自定义标题栏、系统托盘、单实例保护，
  行为与原版 Tauri 桌面端一致。
- 之前的 ofm-egress-2.5.4-portable.zip 是免安装绿色版（cmd 启动 + 浏览器
  访问），适合不想安装的场景；两者可同时运行，数据目录不同
  （本客户端默认 ~/.our-free-model，绿色版用自带 data\）。


卸载
----
设置 → 应用 → 已安装的应用 → Our Free Model → 卸载。
卸载不会删除 ~/.our-free-model（你的 API Key、设置与统计数据），
也不需要先手动停止服务。想彻底清空，卸载后手动删除该目录。


已知限制
--------
- 订阅模式需要本机有 mihomo 可执行文件；没有时请改用单代理模式
  或安装 Clash Verge 等客户端。
- 首次启动新出口需要几秒才通，可用模型数会先降后升，属正常现象。
